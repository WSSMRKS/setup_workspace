# Claude Code CLI Cheatsheet

## Input keybindings

| Key | What it does |
|-----|-------------|
| `Enter` | Submit message/command |
| `Alt+Enter` | New line without submitting |
| `Ctrl+c` | Cancel/exit |

## Common commands

| Command | What it does |
|---------|-------------|
| `/help` | Show available commands and help |
| `/config` | Configure settings (theme, model, etc.) |
| `/code-review` | Review code changes |
| `/verify` | Run and verify changes |
| `/schedule` | Schedule recurring tasks |

## Tips

- Use code blocks (triple backticks) for multi-line code in messages
- Alt+Enter is essential for writing multi-line input without accidental submission
